# Tarmac Car Rental: v2

Лендинг прокату авто + невеликий бекенд для бронювань. **Жодних npm-залежностей**: потрібен лише Node.js 18+.

## Запуск

```bash
cp .env.example .env      # задай свій ADMIN_TOKEN
npm start                 # або: node server/index.js
```

- Сайт: http://localhost:3000
- Адмінка: http://localhost:3000/admin (вхід за `ADMIN_TOKEN`)
- Тести API: `npm test`
- Режим розробки з автоперезапуском: `npm run dev`

Можна відкрити `public/index.html` і без сервера: каталог покажеться з вбудованих даних, а форма бронювання запропонує зателефонувати.

## Структура

```
public/                 фронтенд (статичні файли)
  index.html            головна
  admin.html            «стійка бронювань» для персоналу
  404.html
  css/styles.css        основні стилі (токени кольорів на початку файлу)
  css/admin.css
  js/app.js             логіка сторінки: пошук, фільтри, бронювання, керування бронюванням, зворотний дзвінок
  js/admin.js
  img/                  авто без фону (WebP), іконки з прототипу
server/
  index.js              HTTP-сервер + маршрути API
  http.js               мінімальний роутер на node:http (замість Express)
  store.js              JSON-«база» з атомарним записом (storage/db.json)
  pricing.js            ціни, кількість днів, наявність авто
  validate.js           перевірка вхідних даних
  data/*.json           класи авто, аеропорти, додаткові опції (редагуй тут)
test/api.test.js        тести на вбудованому node:test
```

## API

| Метод | Шлях | Що робить |
|---|---|---|
| GET | `/api/cars` | каталог; з `?locationId=LAX&pickupDate=…&returnDate=…` додає наявність і суму |
| GET | `/api/locations`, `/api/extras` | аеропорти, додаткові опції |
| POST | `/api/quote` | розрахунок ціни (сервер завжди рахує сам, ціну від клієнта ігнорує) |
| POST | `/api/bookings` | створити бронювання → `TM-XXXXXX` |
| GET | `/api/bookings/:ref?email=` | знайти своє бронювання (потрібні і номер, і email) |
| POST | `/api/bookings/:ref/cancel` | безкоштовне скасування до 24 год перед отриманням |
| POST | `/api/callbacks` | заявка «передзвоніть мені» |
| GET/PATCH | `/api/admin/bookings`, `/api/admin/callbacks` | для адмінки, заголовок `Authorization: Bearer <ADMIN_TOKEN>` |

Захист: валідація всіх полів, ліміт запитів за IP, honeypot-поле від ботів, ліміт розміру тіла запиту (10 KB), заголовки безпеки (CSP, nosniff, frame-deny), порівняння токена за сталий час, захист від path traversal у статиці.

## Що змінилося порівняно з прототипом

- **Адаптивність.** Прототип мав жорсткі ширини (1140px, 938px…) і горизонтальний скрол навіть на ноутбуці. Тепер верстка тягнеться від 320px до широких екранів.
- **Навігація.** Липкий хедер, мобільне меню, телефон-кнопка, «Manage booking».
- **Hero.** Замість стокового фото з чужого CDN (hotlink, без нього шапка була порожня): заголовок, форма пошуку (аеропорт, дати, клас) і «дорога» з п’ятьма авто. Клік по машині вибирає клас.
- **Авто без білого фону.** JPG перетворено на прозорі WebP, вони менші і стоять на будь-якому фоні.
- **Список авто.** Фільтри за класом і місцями, сортування, ціна за день і за поїздку, наявність, «залишилось 1».
- **Справжнє бронювання.** Кнопки «Book now» вели на YouTube. Тепер це модальне вікно з датами, опціями, живим підрахунком суми, валідацією і підтвердженням з номером бронювання.
- **Керування бронюванням.** Пошук за номером і email, скасування.
- **Зворотний дзвінок** у синьому блоці «Book by phone»; телефон тепер клікабельний (`tel:`).
- **FAQ**, блок «як це працює», сторінка 404.
- **Виправлено:** у Convertible був опис Economy; кілька `<h1>` на сторінці; шрифти Google підключались двічі; «Suitcase:2» через `&nbsp`; невалідний номер телефону.
- **Доступність і SEO:** семантичні секції, alt-тексти, видимий фокус, skip-link, `prefers-reduced-motion`, meta description, Open Graph, schema.org `AutoRental`.
- Шрифт **Overpass** (на основі Highway Gothic, шрифту дорожніх знаків США) замість Montserrat/Open Sans/Comic Neue. Фірмові кольори (синій, оливковий, бордовий) збережено.

## Перш ніж показувати клієнту

- Ціни, моделі «or similar», аеропорти, кількість машин і відповіді в FAQ — **демо-дані**. Їх задають `server/data/*.json`, тексти FAQ лежать у `index.html`. Якщо міняєш дані, онови й копію `FALLBACK` на початку `public/js/app.js`.
- Телефон `+1 234 567 8908` — заглушка (шукай по проєкту).
- Листи-підтвердження не надсилаються. Щоб додати їх, підключи SMTP (наприклад, через `nodemailer`) у `POST /api/bookings`.
- JSON-файл підходить для прототипу. Для реального навантаження заміни `server/store.js` на SQLite або PostgreSQL: решта коду працює тільки через його функції.
- За nginx або на хостингу (Render, Railway) встанови `TRUST_PROXY=1`, щоб ліміт запитів бачив справжні IP.
